## 1. FASES DE DESARROLLO POST-MVP

### Fase 1 — MVP (Mes 1)
**Objetivo:** Validar el concepto con usuarios reales

Incluye:
- Villa Amparo + Bosque de Letras
- Vocales completas (A, E, I, O, U)
- 3 mini-juegos educativos
- Casa básica decorable
- 3 misiones principales
- AIProviderService básico (Claude/OpenAI)

### Fase 2 — Consolidación (Mes 2-3)
**Objetivo:** Completar el mundo educativo central

Nuevos componentes:
- Ciudad de Palabras (consonantes básicas M, P, L, S, T)
- 10 mini-juegos adicionales
- Sistema de escritura por arrastre
- Misiones diarias automáticas
- Panel de padres completo
- Sumas visuales hasta 5
- 20+ muebles adicionales
- Sistema de mascotas con comportamientos
- Logros completos
- AIProviderService con adaptación real

### Fase 3 — Expansión (Mes 4-6)
**Objetivo:** Agregar las 3 zonas restantes y matemáticas

Nuevos componentes:
- Montaña de Cuentos (comprensión lectora)
- Isla Matemática (sumas y restas hasta 10)
- Granja Educativa (conteo avanzado)
- Parque de Creatividad (escritura creativa)
- Abecedario completo (27 letras)
- Generación de historias por IA
- Generación de misiones personalizadas por IA
- Sistema de amigos NPC completo (niveles de amistad)
- Nueva habitación: Cocina

### Fase 4 — Profundización (Mes 7-9)
**Objetivo:** Contenido avanzado y fidelización

Nuevos componentes:
- Mundo Submarino (pensamiento lógico)
- Sílabas y palabras de 3+ letras
- Comprensión lectora nivel avanzado
- Restas visuales
- Patrones y secuencias
- Modo "Guardián de Villa Amparo" (nivel 10)
- Nueva habitación: Biblioteca mágica
- Nueva habitación: Laboratorio
- Sistema de eventos especiales (Halloween, Navidad, etc.)
- App móvil nativa (iOS + Android)

### Fase 5 — Plataforma (Mes 10-18)
**Objetivo:** Convertirse en plataforma educativa

Nuevos componentes:
- Modo Multiplayer Local (2 jugadores en el mismo dispositivo)
- Modo Clase (1 maestro + 30 alumnos)
- Currículo oficial alineado a programas nacionales
- Panel avanzado para educadores
- Exportación de reportes para escuelas
- API para integración con LMS (Moodle, Google Classroom)
- Programa de certificación para escuelas

## 2. MODELO DE MONETIZACIÓN

### Principios de Monetización

1. **Sin pay-to-win** — Todo el contenido educativo disponible para todos
2. **Sin anuncios** — Nunca publicidad dentro del juego
3. **Sin compras in-app con dinero real** — Todo se desbloquea jugando
4. **Modelo de suscripción justo y predecible**

### Tiers de Suscripción

#### 🆓 Free Tier — "Explorador"
**Precio:** $0/mes

Incluye:
- 1 perfil de niño
- Villa Amparo + Bosque de Letras
- Vocales A, E, I, O, U
- 5 mini-juegos
- Casa básica (1 habitación)
- Progreso guardado en la nube
- Sistema de voz básico

**Objetivo:** Adquisición de usuarios, demostración del producto

#### 💎 Premium — "Aventurero"
**Precio:** $7.99/mes (o $59.99/año — ahorra 37%)

Incluye todo lo de Free +
- Hasta 2 perfiles de niños
- Todas las zonas del mundo (8 zonas)
- Abecedario completo + matemáticas avanzadas
- Todos los mini-juegos (20+)
- Casa completa (7 habitaciones)
- Catálogo completo de objetos
- Todas las mascotas
- IA adaptativa completa
- Voz premium (ElevenLabs)
- Generación de historias personalizadas
- Panel de padres completo con reportes
- Misiones generadas por IA

#### 👨‍👩‍👧‍👦 Family Plan — "Gran Familia"
**Precio:** $11.99/mes (o $89.99/año)

Incluye todo lo de Premium +
- Hasta 5 perfiles de niños
- Modo familia (ver progreso comparativo)
- Herramientas para educación en casa

#### 🏫 Educación — "Escuela"
**Precio:** Desde $99/mes (por aula)

Incluye todo lo de Family +
- Panel de educadores
- Hasta 30 alumnos por aula
- Reportes para el aula
- Currículo alineado a programa escolar
- Presentaciones para la clase
- Soporte prioritario
- Onboarding con el equipo

### Estrategia de Conversión Free → Premium

1. **Teaser de contenido:** El niño desbloquea el camino a Ciudad de Palabras pero no puede entrar en Free
2. **Pantalla de upgrade:** Lumi dice "¡Quiero enseñarte más letras! Pídele a tus papás que continúen la aventura."
3. **Prueba gratuita:** 7 días de Premium gratis al registrarse
4. **Email a padres:** Reporte de progreso con "Tu hijo está listo para el siguiente nivel"

## 4. ESCALAMIENTO TÉCNICO

### Infraestructura por Tamaño

#### Hasta 1,000 usuarios (Mes 1-6)
```
Frontend: Vercel Hobby → Pro ($20/mes)
Backend:  Supabase Free → Pro ($25/mes)
IA:       Claude/OpenAI pay-as-you-go (~$50/mes)
TTS:      ElevenLabs Starter → Creator ($22/mes)
CDN:      Cloudflare Free

Total infra: ~$120/mes
```

#### 1,000 - 10,000 usuarios (Mes 6-18)
```
Frontend: Vercel Pro ($20/mes)
Backend:  Supabase Pro ($25/mes) + Read replicas
IA:       AIProviderService con múltiples proveedores
          (balanceo de carga entre Claude + Gemini)
TTS:      ElevenLabs Business ($99/mes)
CDN:      Cloudflare Pro ($20/mes)
Assets:   Cloudflare R2 para modelos 3D

Total infra: ~$300/mes
```

#### 10,000+ usuarios (Mes 18+)
```
Frontend: Vercel Enterprise o AWS CloudFront
Backend:  Supabase Enterprise o PostgreSQL en AWS RDS
IA:       AIProviderService con routing inteligente
          (costo + latencia + calidad)
TTS:      Servidor propio de TTS (Coqui/XTTS) + ElevenLabs
Assets:   CDN dedicada por región (AWS CloudFront)
Cache:    Redis para sesiones y respuestas de IA

Total infra: ~$2,000-5,000/mes (con revenues de $50K+/mes)
```

### Optimizaciones de IA a Escala

```typescript
// A escala, AIProviderService implementa routing inteligente

class ScalableAIRouter {
  route(task: AITask): string {
    // Tareas simples → modelo más económico
    if (task.type === 'motivational_message') return 'gemini-flash'
    if (task.type === 'generate_hint') return 'claude-haiku'

    // Tareas complejas → modelo más capaz
    if (task.type === 'generate_story') return 'claude-sonnet'
    if (task.type === 'generate_parent_report') return 'claude-sonnet'

    // Balance por carga actual del proveedor
    if (this.getProviderLoad('claude') > 0.8) return 'openai'

    return this.defaultProvider
  }
}
```

### Hoja de Ruta Curricular

- Números 1-20

- Sílabas complejas (bra, tra, cla, etc.)
- Lectura fluida de frases de 5+ palabras
- Multiplicación visual (grupos de objetos)
- Formas geométricas básicas
- Vocabulario: 500+ palabras

#### Año 3: Primaria Intermedia
- Lectura autónoma de párrafos cortos
- División visual básica
- Fracciones con pizzas/tortas

Después de consolidar español:

4. Potencialmente 10+ idiomas a largo plazo

                    │

    (Supabase)  (Cache)    (Load Balance)
                               │
              ┌────────────────┼────────────────┐
              │                │                │

           (Primary)     (Secondary)       (Fallback)
