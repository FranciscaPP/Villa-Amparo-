## 1. FUNDAMENTOS PEDAGÓGICOS

### Marco Teórico

Villa Amparo se basa en investigación educativa probada:

**Método Fonético Global (Whole Language + Phonics):**
- Los niños aprenden sonidos (fonética) antes que nombres de letras
- Contexto significativo desde el primer día
- Inmersión en lenguaje escrito natural

**Aprendizaje Basado en Juego (Play-Based Learning):**
- El juego es el vehículo del aprendizaje
- Motivación intrínseca (no externa)
- Exploración libre con guía suave

**Zona de Desarrollo Próximo (Vygotsky):**
- El sistema siempre opera en el borde del conocimiento del niño
- Desafíos que son posibles con esfuerzo (no triviales, no imposibles)
- El tutor IA actúa como el "adulto más capaz" de Vygotsky

**Espaciado y Repetición (Spaced Repetition):**
- Contenido aprendido se revisa en intervalos crecientes
- Previene el olvido
- Consolida memoria a largo plazo

**Multimodalidad:**
- Visual: imágenes grandes, colores, animaciones
- Auditivo: voz narradora, sonidos, música
- Kinestésico: drag & drop, tapping, interacción directa

### Principios de No-Frustración

```
ZONA ÓPTIMA DE APRENDIZAJE

     Dificultad
         ↑
         │ Demasiado difícil (frustración)
         │━━━━━━━━━━━━━━━━━━━━━━━━━
    Alta │   ZONA DE FLUJO ÓPTIMO
         │    (70-80% tasa de éxito)
         │━━━━━━━━━━━━━━━━━━━━━━━━━
    Baja │ Demasiado fácil (aburrimiento)
         └────────────────────────→
                                 Habilidad del niño
```

El sistema IA mantiene al niño siempre en la zona de flujo:
- Si tasa de éxito > 85% → aumentar dificultad
- Si tasa de éxito < 65% → reducir dificultad
- Si tasa de éxito 65-85% → mantener dificultad

## 2. CURRÍCULO DE LECTURA

### Nivel 0: Pre-Lectora (Edad 4-5)

**Objetivos:**
- Distinguir letras de números y dibujos
- Entender que las letras representan sonidos
- Escuchar rimas y aliteraciones
- Reconocer el propio nombre escrito

**Actividades:**
- Clasificar tarjetas: ¿letra o dibujo?
- ¿Cuál empieza igual que tu nombre?
- Rimas con personajes: "Memo rima con... ¿nemo? ¿teléfono?"
- Encontrar la inicial del propio nombre en el mundo

### Nivel 1: Vocales (Edad 5)

**Objetivos:**
- Reconocer y nombrar las 5 vocales
- Asociar cada vocal con su sonido
- Identificar objetos que comienzan con cada vocal
- Reconocer vocales en palabras simples

**Secuencia de Aprendizaje:**
```
Semana 1: A
  - Presentación de Ana la A (animación)
  - Sonido: "aaaa" (boca abierta)
  - Palabras: árbol, avión, araña
  - Actividades: atrapar A's, ¿cuál empieza con A?

Semana 2: O
  - Presentación de Ola la O (animación)
  - Sonido: "oooo" (labios redondeados)
  - Palabras: oso, oveja, ojo

Semana 3: E
  - Presentación de Ema la E
  - Repaso de A y O

Semana 4: I
  - Presentación de Ivo la I
  - Repaso de A, O, E

Semana 5: U
  - Presentación de Ugo la U
  - Repaso de todas las vocales
  - ¡Logro: Maestro de Vocales!
```

### Nivel 2: Consonantes Básicas (Edad 5-6)

**Orden de presentación** (por frecuencia en español):

```
Grupo 1 (Alta frecuencia, fonema simple):
  M, P, L, S, T, N, D

Grupo 2 (Alta frecuencia, requiere práctica):
  R (suave y fuerte), C/Q, B/V, F, J

Grupo 3 (Menor frecuencia):
  G, H (muda), CH, LL, Ñ, Y, Z, X

Grupo 4 (Difásicas y especiales):
  DR, TR, BL, BR, PL, PR, CL, CR
```

### Nivel 3: Sílabas Directas (Edad 6)

**Estructura:** Consonante + Vocal

```
Con M: MA - ME - MI - MO - MU
  Palabras: MAMÁ, MESA, MIRO, MOTO, MULA

Con P: PA - PE - PI - PO - PU
  Palabras: PAPÁ, PEPA, PINO, POLO, PUMA
```

**Actividad: El Tren de Sílabas**
```
[M] + [A] → [MA] ← El niño arrastra las letras para unirlas
Lumi: "¡M con A hace... MA! ¡MA de MAMÁ!"
```

### Nivel 4: Palabras Bisílabas (Edad 6-7)

```
MA + MÁ = MAMÁ
ME + SA = MESA
CA + SA = CASA
PA + TO = PATO
```

**Actividad: Construir Palabras**
```
El niño ve la imagen de una casa.
Lumi: "¿Puedes construir la palabra CASA?"
Se muestran letras: C, A, S, A (y otras de distractor)
El niño arrastra en orden: C → A → S → A
```

### Nivel 5: Oraciones Simples (Edad 7)

```
MAMÁ AMA A PAPÁ.
EL GATO COME PECES.
LA CASA ES GRANDE.
```

### Nivel 6: Lectura Comprensiva Básica (Edad 7-8)

```
EL NIÑO Y EL PERRO

EL NIÑO SE LLAMA LUCAS.
LUCAS TIENE UN PERRO.
EL PERRO SE LLAMA MAX.
MAX ES MUY ALEGRE.
LUCAS Y MAX SON AMIGOS.

¿Cómo se llama el perro de Lucas?
[MAX] [LUCAS] [PEDRO]
```

## 3. CURRÍCULO DE ESCRITURA

### Nivel 1: Pre-Escritura (Edad 5)

**Actividades:**
- Trazar líneas horizontales, verticales y curvas
- Seguir el trazo de letras grandes (dedo en pantalla)
- Colorear dentro de formas

**Mecánica: El Trazado de Letras**
```
La letra A aparece en punteado grande.
Lumi: "Vamos a dibujar la A. Sigue los puntitos."
El niño sigue el trazo con el dedo/mouse.
Retroalimentación visual: el trazo se ilumina al hacerlo correctamente.
```

### Nivel 2: Escritura por Arrastre (Edad 5-6)

**No requiere escritura manual en pantalla.**
El niño selecciona letras de una barra y las arrastra a los espacios.

```
C _ S _
[A] [B] [A] [S] [T] [O]

El niño arrastra las letras correctas para completar CASA.
```

### Nivel 3: Completar Palabras (Edad 6-7)

```
MA_Á  (falta la M del medio)
P_PA  (falta la A)
CA__  (faltan S y A)
```

### Nivel 4: Teclado Virtual (Edad 7-8)

Para niños que ya dominan letras individuales, un teclado virtual completo:
- Las teclas son grandes (mínimo 50x50px)
- Al presionar cada tecla: la letra se pronuncia
- Sugerencias visuales de las letras posibles

## 4. CURRÍCULO DE MATEMÁTICAS

### Nivel 1: Reconocimiento de Cantidades (Edad 5)

**Objetivos:**
- Contar objetos del 1 al 5
- Reconocer los numerales 1-5
- Comparar: más / menos / igual

**Actividades:**
```
¿Cuántos peces hay? [1] [2] [3]
[🐟🐟🐟] ← El niño cuenta tocando cada pez

¿Cuál tiene más? 
[🍎🍎] vs [🍎🍎🍎🍎]
```

### Nivel 2: Conteo hasta 10 (Edad 5-6)

**Actividades:**
```
La Granja Mágica:
Berta: "Cuéntame cuántas gallinas hay."
[🐔🐔🐔🐔🐔🐔🐔] = 7

Lumi: "¿Puedes tocar cada gallina y contar?"
[Al tocar cada una → hace "cloc" y se ilumina]
"1... 2... 3... 4... 5... 6... 7!"
"¡Siete gallinas!"
```

### Nivel 3: Suma Visual (Edad 6)

**Presentación siempre con objetos concretos:**

```
┌─────────────────────────────┐
│  🍎🍎🍎    +    🍎🍎         │
│  3 manzanas + 2 manzanas   │
│                             │
│  ¿Cuántas hay en total?    │
│                             │
│  [3]  [4]  [5]  [6]        │
└─────────────────────────────┘

Lumi: "Tenemos 3 manzanas aquí [señala],
       y 2 más aquí [señala].
       ¿Cuántas hay en total?"
```

### Nivel 4: Resta Visual (Edad 7)

```
┌─────────────────────────────┐
│  🍕🍕🍕🍕🍕                  │
│  5 pizzas                  │
│                             │
│  [come 2 pizzas]           │
│  🍕🍕 ✗  🍕🍕🍕              │
│                             │
│  ¿Cuántas quedan?          │
│  [2]  [3]  [4]             │
└─────────────────────────────┘
```

### Nivel 5: Problemas de Contexto (Edad 7-8)

```
Historia: El mercado de Villa Amparo
"Tenías 8 monedas. Compraste un libro por 3 monedas.
¿Cuántas monedas te quedan?"

Visual: 8 monedas → se van 3 → quedan ?
```

### Nivel 6: Patrones y Secuencias (Edad 7-8)

## 5. CURRÍCULO DE COMPRENSIÓN LECTORA

### Modelo de Preguntas por Nivel

**Nivel 1: Literal Simple**
- ¿Qué hay en la imagen?
- ¿De qué color es X?
- ¿Cuántos hay?

**Nivel 2: Literal en Texto**
- ¿Cómo se llama el personaje?
- ¿Dónde ocurrió la historia?
- ¿Qué hizo el personaje?

**Nivel 3: Inferencial Básico**
- ¿Por qué está triste el personaje?
- ¿Qué crees que pasará después?
- ¿Cómo se siente X?

**Nivel 4: Vocabulario en Contexto**
- ¿Qué significa la palabra X en esta historia?
- ¿Cuál es otra forma de decir X?

### Formato de Actividad de Comprensión

```
HISTORIA (narrada completamente por Lumi):
"Luna era una mariposa que vivía en el Bosque de las Letras.
Un día, Luna encontró una flor muy especial.
La flor cantaba canciones de letras.
Luna estaba muy feliz."

[Imágenes grandes acompañan cada oración]

PREGUNTAS (3 máximo por historia):

Pregunta 1 (literal):
Lumi: "¿Quién es la protagonista de la historia?"
[Imagen de mariposa] [Imagen de flor] [Imagen de árbol]

Pregunta 2 (literal):
Lumi: "¿Qué encontró Luna?"
[Imagen de flor] [Imagen de piedra] [Imagen de nube]

Pregunta 3 (emocional):
Lumi: "¿Cómo se sentía Luna al final?"
[Cara feliz] [Cara triste] [Cara asustada]
```

| 8 | L | Alta frecuencia, sonido claro |
| 9 | S | Alta frecuencia, plural |
| 10 | T | Alta frecuencia, fácil de reconocer |
| 11 | N | Alta frecuencia, par con M |

| 16 | F | Fonema claro |
| 17 | G (ga,go,gu) | Antes de la G suave |

| 21 | CH | Dígrafo frecuente |
| 22 | LL/Y | Yeísmo — presentar juntos |
| 23 | Ñ | Único en español |

## 8. MECÁNICAS DE ACTIVIDADES

### Mecánica 1: Reconocimiento de Letra

**Descripción:** El niño debe identificar la letra objetivo entre distractores.

```
Dificultad 1: 1 objetivo + 2 distractores muy diferentes
  [A] [T] [9]  → Tocar la A

Dificultad 2: 1 objetivo + 3 distractores
  [A] [T] [9] [D]  → Tocar la A

Dificultad 3: 2 objetivos + 4 distractores
  [A] [T] [A] [D] [9] [L]  → Tocar las dos A

Dificultad 4: Letras similares como distractores
  [A] [Á] [4] [Â]  → Tocar la A sin acento
```

### Mecánica 2: Asociación Fonética

**Descripción:** El niño escucha un sonido y debe identificar la letra.

```
Lumi hace el sonido: "Mmmmmm..."
El niño debe tocar la letra correspondiente:
[M] [N] [P]
```

### Mecánica 3: Construir Sílabas (Drag & Drop)

```
[_] [_] → completar MA
Letras disponibles: [M] [A] [T] [O] [S]

El niño arrastra: M → primera casilla
                  A → segunda casilla

¡Animación: MA explota con confeti!
Lumi: "¡MA! ¡Como en MAMÁ!"
```

### Mecánica 4: Completar Palabra

```
Imagen: 🏠
Palabra: C_SA
Letras disponibles: [A] [E] [I] [O] [U]

Respuesta: A (para hacer CASA)
```

### Mecánica 5: Asociación Palabra-Imagen

```
Lumi dice: "PERRO"
Opciones visuales (sin texto):
[imagen de perro] [imagen de gato] [imagen de pez]
```

### Mecánica 6: Contar Objetos

```
[🌟🌟🌟🌟🌟]
Lumi: "¿Cuántas estrellas hay?"
[3] [4] [5] [6]

Al seleccionar → las estrellas se cuentan animadas con voz
```

### Mecánica 7: Suma Visual

```
[🍎🍎🍎] [+] [🍎🍎]

Lumi: "¿Cuántas manzanas hay en total?"
El niño puede tocar cada manzana para contarlas
[4] [5] [6] [7]
```

### Mecánica 8: Comprensión de Historia

```
Historia narrada (3-5 oraciones)
    ↓
3 preguntas de opción múltiple visual
(máximo 3 opciones por pregunta)
    ↓
Siempre narradas completamente
```

## 10. EVALUACIÓN CONTINUA

### Métricas Recopiladas por Actividad

Cada actividad registra:
- Tipo de actividad
- Tema (letra, número, palabra)
- Resultado (correcto/incorrecto)
- Número de intentos
- Tiempo de respuesta (ms)
- Zona donde ocurrió

### Cálculo de Dominio por Habilidad

```
Dominio de Letra = (correctas / totales) × peso_por_intentos

Donde peso_por_intentos:
  1er intento: 1.0
  2do intento: 0.7
  3er intento: 0.4
  4to+ intento: 0.2

Umbral de dominio: > 0.8 = dominado (verde)
                   0.5-0.8 = aprendiendo (amarillo)
                   < 0.5 = necesita práctica (naranja)
```

### Frecuencia de Revisión (Spaced Repetition)

```
Dominio 0.8-1.0: Revisar en 7 días
Dominio 0.6-0.8: Revisar en 3 días
Dominio 0.4-0.6: Revisar en 1 día
Dominio < 0.4:   Revisar en la misma sesión
```
